# SITEVL X-RAY — переработка в физический кодовый слой

Дата: 6 сентября 2026 года. Проект: существующий `ay-digital.ru`.

Результат реализован в рабочей копии. Это не отдельный сайт и не макет. Production-деплой, commit и push в рамках этого задания не выполнялись.

## 1. Что было раньше

Старая реализация открывала панель кода справа и управляла её шириной ползунком. `definitionBuilders.ts` и `loadXRayDefinition.ts` собирали подготовленные текстовые представления страниц и данных. Они не давали точного соответствия между наведённым DOM-элементом и строкой реально собранного JSX.

Удалены оба генератора старых определений, старый разворачивающийся редактор и его CSS. Контроллер и Experience заменены, а не продублированы. Существующий allowlist публичных маршрутов сохранён.

## 2. Новая архитектура

```text
Сборка Vite
  → явный allowlist 24 frontend-файлов
  → разбор реального TSX через TypeScript AST
  → data-xray-node на поддерживаемых JSX-узлах
  → безопасный manifest JSX-фрагментов, файлов и номеров строк

Браузер после включения X-RAY
  → кодовый фон, z-index: 0, pointer-events: none
  → существующий #xray-live-site, z-index: 1, opacity: 0.55
  → outline / box model
  → компактный контроллер и инспектор
```

Сайт не клонируется и не заменяется картинкой. Меняется прозрачность существующего layout-контейнера, а не `body`. Шапка, содержимое, изображения и текущая прокрутка остаются настоящими.

`CodeLayer` располагается за сайтом. Положение каждого видимого кодового раздела вычисляется по `getBoundingClientRect()` соответствующей секции. Прокрутка сайта и кода общая; отдельного большого редактора с независимой прокруткой нет.

Используется [virtual module Vite](https://vite.dev/guide/api-plugin.html#virtual-modules-convention), а не HTTP endpoint для чтения файлов. TypeScript-парсер работает только при сборке и не отправляется в браузер.

## 3. Работающие возможности

- Включение кнопкой `</> X-RAY` или физической клавишей X; повторное нажатие выключает режим. Набор X внутри поля не переключает X-RAY.
- Scan-анимация при входе и выходе. При `prefers-reduced-motion` scan и переход прозрачности отключены.
- Непрозрачность сайта 25–85%, по умолчанию 55%.
- Яркость кодового слоя 25–100%, независимо от непрозрачности сайта.
- «Фокус кода» и временный просвет до 20% при удержании Option / Alt.
- CODE: реальные JSX-фрагменты либо безопасный HTML текущего DOM.
- STRUCTURE: дерево фактических DOM-узлов с названиями сопоставленных компонентов.
- BOX MODEL: вычисленные margin, border, padding и content; отдельные цветовые слои.
- Hover: рамка, подпись компонента/тега, подсветка настоящего диапазона строк.
- Click / touch tap: компактный инспектор с JSX или HTML, CSS, DATA, объяснением и копированием безопасного фрагмента.
- CSS показывает вычисленные `getComputedStyle` значения. Они не выдаются за оригинальный CSS-файл.
- DATA показывает ограниченный список DOM-атрибутов. React props/state не читаются.
- Список разрешённых файлов, реально встречающихся на текущей странице; просмотр JSX-фрагментов.
- Контроллер сворачивается при открытии инспектора, чтобы панели не перекрывались. На телефоне управление изначально компактное.
- «Выбор элементов» можно выключить для обычного использования ссылок и кнопок. Прокрутка не блокируется и в режиме выбора.
- Escape сначала закрывает инспектор/список, затем сам X-RAY; фокус возвращается без сброса прокрутки.
- Experimental Reveal Lens: локальная [CSS-маска](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-image) следует за указателем. При отсутствии поддержки масок кнопка недоступна с объяснением.

## 4. Поддерживаемые исходники и mapping

Сборка проверена на 24 файлах, 984 сопоставлениях JSX-узлов и 2798 строках JSX-фрагментов.

Компоненты:

`Header`, `Footer`, `PageHero`, `ServiceCard`, `TrustBlocks`, `CallToAction`, `CaseGallery`, `EditorialPhoto`, `WebStudioHero`.

Шаблоны страниц:

`HomePage`, `ServicesPage`, `PricesPage`, `PriceDirectionPage`, `CasesPage`, `CasePage`, `MobileAppsPage`, `SeoLandingPage`, `UsefulIndexPage`, `UsefulArticlePage`, `LocalSeoPage`, `AboutPage`, `ProcessPage`, `LegalPage`, `ChangelogPage`.

Полный allowlist — `scripts/xray-source-plugin.mjs`. Изменять сами 24 исходника вручную ради аннотаций не требуется: аннотации добавляет build transform перед React-плагином.

ID содержит идентификатор разрешённого файла, исходную строку и колонку. Реестр хранит компонент, тег, начало и конец JSX-узла. Повторные экземпляры одной карточки закономерно указывают на один исходный JSX.

Например, H1 главной сопоставлен с `src/pages/HomePage.tsx:93` и реальным выражением `<h1>{pageMeta.home.title}</h1>`. Несуществующий `Hero.tsx` не создавался ради картинки из референса.

Для компонентов вне allowlist доступны фактический безопасный DOM и вычисленные стили, но не придуманный JSX. Пользовательские формы и результаты на `/ai-website`, `/brief`, `/contacts` полностью исключены из исследования main-контента; шапка и подвал остаются доступны. Исключение работает также с завершающим `/`.

LAB, внутренние Studio/административные маршруты и неизвестные маршруты не получают новый X-RAY: сохранена существующая граница публичных страниц.

## 5. Безопасность

Применены независимые ограничения сборки и runtime:

1. Только явные frontend-пути; нет glob по всему `src`, чтения зависимостей или произвольного пути из браузера.
2. Путь проверяется после `realpath`; symlink, выход за allowlist и превышение лимитов приводят к ошибке сборки.
3. Публикуются только символы внутри действительных AST-границ JSX. Импорты, конфигурация, константы, hooks и обработчики вне JSX исключены, даже если записаны на той же строке.
4. Подозрительные строки с env, API endpoints, authorization, ключами, паролями, JWT и HTTP-адресами с query удаляются из представления целиком. Контактные литералы редактируются.
5. Нет чтения `.env`, serverless-кода, Vercel/Redis/Gemini/Telegram credentials, sourcemaps или backend-конфигурации.
6. DOM-обход не читает `innerHTML` контейнера, значения полей, React Fiber/props/state, cookies, localStorage или sessionStorage. Текст читается отдельно от приватных потомков.
7. `form`, поля ввода, contenteditable, dialogs, iframe, script/style, hidden и явные private/sensitive области исключены. Приватные дочерние узлы не попадают даже в название секции.
8. DATA ограничен тегом, безопасными классами/role и безопасными атрибутами изображения. Адреса ресурсов ограничены публичными локальными каталогами, query-параметры отбрасываются.
9. Вывод и подсветка — React text nodes, не `dangerouslySetInnerHTML`.
10. Копирование использует тот же уже очищенный фрагмент, который показан в инспекторе. При отказе Clipboard API доступна повторная попытка, успех не имитируется.

Это дополнительная защита учебного просмотра frontend, а не способ хранить секреты в React. Секреты по-прежнему должны оставаться server-side.

## 6. Производительность и выключение

- Experience, manifest и стили загружаются динамически только после активации. Браузерная проверка до первого включения не обнаружила загрузку Experience chunk.
- Итоговый JS chunk Experience: 386369 байт, gzip 65878 байт. Manifest: 373833 символа JSON. В нём только разрешённые данные.
- Нет Monaco, CodeMirror, runtime TypeScript-парсера и новых npm-зависимостей.
- Кодовые секции отрисовываются только около viewport. DOM-выбор, измерения и движение указателя объединяются через requestAnimationFrame.
- MutationObserver/ResizeObserver и X-RAY pointer/scroll listeners существуют только во включённом режиме. На выходе они отключаются, кадры и таймеры отменяются, временные CSS-переменные и активные атрибуты снимаются.
- В выключенном состоянии остаются лёгкая кнопка, shortcut и статические build-time mapping-атрибуты. Это не постоянное сканирование страницы.
- При SPA-переходе mapping/выделение обновляются; при переходе на неподдерживаемую страницу слой удаляется.

## 9. Как открыть

При запущенном preview: `http://localhost:4173/`, затем кнопка X-RAY или X. В текущем `/lab` кнопки нет — это намеренно сохранённая граница маршрутов.

Для повторного запуска:

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

Для локального браузерного QA с установленным agent-browser:

```sh
node scripts/qa-xray.mjs
```

Если CLI не в PATH, можно указать путь к нему через `SITEVL_BROWSER_BIN`. Поддерживается путь к CLI `.js`; provider secrets для QA не нужны.

## 10. Ограничения и следующая версия

- Проверка touch выполнена в настоящем Chromium с эмуляцией устройства через browser input protocol; это не физический iPhone и не проверка Safari. Safari/VoiceOver и физические устройства остаются NOT TESTED.
- Reveal Lens имеет Experimental-статус. Её поведение на конкретном GPU/браузере стоит дополнительно проверить на физических устройствах.
- Публикуется выбранный frontend JSX, а не весь репозиторий. Файловый просмотр ограничен 160 строками фрагментов, отдельный элемент — 90 строками; это учебный инспектор, не полноценный IDE.
- CSS является вычисленным снимком. Сопоставление селектора с оригинальным CSS-файлом, source navigation по обработчикам и React props/state сознательно не реализованы.
- Box model использует текущую экранную рамку и вычисленные отступы. Отрицательные margin доступны численно в CSS; кольцо визуализирует неотрицательные отступы. Сложные rotate/3D transforms не являются точной геометрической моделью.
- Во второй версии разумны постраничный просмотр длинных JSX-фрагментов, дополнительный ручной allowlist компонентов, отдельный безопасный CSS source mapping и физическая проверка Safari. Это не требует открывать приватные данные.
- Эта работа проверена локально. Публикация новой версии на `sitevl.tech` требует отдельного release/deploy; существующий production не изменялся.
