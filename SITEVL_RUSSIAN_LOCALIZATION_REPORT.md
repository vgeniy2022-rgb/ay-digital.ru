# Отчёт о русской локализации SITEVL

Дата: 28 августа 2026 года.

## Результат

- **PASS — SITEVL Studio:** добавлена единая русская локализация навигации, действий, статусов, адаптивных режимов, 34 типов блоков, полей инспектора и значений настроек.
- **PASS — Puck:** 72 встроенные строки передаются через официальный `dictionary`; `node_modules` не изменялся.
- **PASS — шаблоны:** пользовательские категории, секции и демонстрационный контент русскоязычных шаблонов локализованы; вымышленные бренды сохранены.
- **PASS — SITEVL LAB:** существующая русская локализация сохранена; отдельно уточнено пользовательское название приложения рисования.
- **PASS — игры, SITEVL OS, Retro, Infinite Canvas:** обычный интерфейс в проверенных сценариях русскоязычный; команды, форматы и атмосферные технические обозначения сохранены.
- **PASS — публичный SITEVL:** неоправданных критических английских действий в основных пользовательских элементах не обнаружено; маркетинговые тексты не переписывались.
- **PASS — совместимость:** внутренние component IDs, schema keys, IndexedDB, localStorage, маршруты, импорт и экспорт не переименовывались.

## Объём

В центральном словаре Studio теперь 220 отображаемых русских значений: 24 общих подписи, 34 названия компонентов, 22 поля, 60 значений настроек, 8 дополнительных замен и 72 строки Puck. Добавлены два автоматических теста критического UI.

## Изменённые части

- `src/features/site-builder/i18n/ru.ts` — единый словарь Studio и Puck.
- `src/features/site-builder/editor` — русские поля и варианты адаптивности.
- `src/features/site-builder/components/StudioPanels.tsx` — страницы, медиа и тема.
- `src/features/site-builder/pages` — редактор, проекты и предпросмотр.
- `src/features/site-builder/templates/templates.ts` — русские категории и демонстрационные тексты.
- `src/features/lab/os/OsSimulatorPage.tsx` — пользовательское название приложения рисования.
- `src/features/site-builder/i18n/localization.test.ts` — lightweight-аудит критических подписей.

## Проверки

- **PASS — `npm test`:** 25/25 тестов.
- **PASS — `npm run lint`:** ошибок нет.
- **PASS — `npx tsc -b --pretty false`:** ошибок нет.
- **PASS — `npm run build`:** Vite-сборка успешна; создан 61 URL sitemap и 74 prerendered HTML; SEO-аудит проверил 61 индексируемый URL.

## Намеренно не переводится

SITEVL, SITEVL Studio, SITEVL LAB, HTML, CSS, JavaScript, TypeScript, React, Vite, Three.js, WebGL, API, SEO, URL, JSON, GitHub, Vercel, IndexedDB, localStorage, FPS, CPU, GPU, RAM, BIOS, CRT, форматы файлов, команды терминала, CORE и другие явно технические элементы игровой эстетики.

## Ограничения

После обновления `@puckeditor/core` следует повторно проверить новые ключи словаря. Строки сторонней библиотеки, не представленные в её публичном `dictionary`, нельзя безопасно заменять без изменения `node_modules` или хрупкого DOM-патча; такие методы в проект не добавлялись.

Коммит, push и deploy не выполнялись.
