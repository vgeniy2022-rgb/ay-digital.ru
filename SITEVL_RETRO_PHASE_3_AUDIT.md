# SITEVL Retro Phase 3 — аудит

Дата: 28 августа 2026 года.

## Исходное состояние

Маршрут `/lab/retro` содержал две работающие темы (`desk95`, `classic`), простой общий оконный слой, статический список файлов, заметку в отдельном localStorage-ключе, Paint с карандашом, калькулятор, терминал и Snake. Дискета была декоративным переключателем, браузера и общей файловой модели не было.

## Ограничения, сохранённые при реализации

- Маршрут и существующие две системы сохранены.
- SITEVL Studio и остальные LAB-модули не изменялись, кроме общего каталога достижений и русских описаний Retro.
- Реальная аппаратная эмуляция, proxy, CSP/X-Frame bypass, `eval` и HTML injection не добавлялись.
- Apple-логотип, Finder face, оригинальные bitmap assets и названия продуктов Apple не используются.
- Внешний iframe ограничен стандартной политикой браузера и `sandbox`.

## Найденные технические риски

- Сторонняя страница не обязана сообщать родителю причину блокировки iframe; надёжно определить X-Frame-Options из клиентского JavaScript невозможно из-за same-origin policy.
- Data URL рисунков могут увеличивать localStorage; для музейных небольших изображений это допустимо, но массовая медиатека потребует IndexedDB.
- Полноэкранный API на iPhone может быть недоступен; интерфейс сохраняет мобильную полноэкранную компоновку окон как CSS-фолбэк.
