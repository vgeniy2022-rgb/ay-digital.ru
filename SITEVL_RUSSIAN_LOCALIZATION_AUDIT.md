# Аудит русской локализации SITEVL

Дата проверки: 28 августа 2026 года.

## Область проверки

Проверены пользовательские строки в `src/features/site-builder`, `src/features/lab`, `src/pages`, `src/components` и `src/data` для файлов TypeScript, TSX, JavaScript, JSX и JSON. В поиск вошли подписи кнопок и вкладок, `aria-label`, подсказки, поля, меню, диалоги, состояния сохранения, шаблоны, HUD игр, SITEVL OS, Retro и Infinite Canvas. `node_modules` не изменялся.

## Найдено и исправлено

### SITEVL Studio

- Смешанные английские вкладки конструктора: Blocks, Outline, Pages, Components, Assets, Style.
- Действия верхней панели: Publish, Preview, Share, Export, Import и статусы сохранения.
- Названия категорий и всех пользовательских блоков конструктора.
- Подписи адаптивных режимов, полей макета, вариантов отображения и значений настроек.
- Разделы страниц, медиатеки, темы и SEO-настроек.
- Подписи встроенного интерфейса Puck: структура, действия блока, массивы, rich text, масштаб и панели.
- Пользовательский демонстрационный контент русскоязычных шаблонов.

Внутренние идентификаторы `Hero`, `Grid`, `Section`, `VerticalStack` и другие сохранены. Русский применяется только к отображаемому `label`, поэтому существующие проекты в IndexedDB остаются совместимыми.

### SITEVL LAB и эксперименты

Основной LAB, игры, физическая лаборатория, SITEVL OS, Retro и Infinite Canvas уже были преимущественно русскоязычными. Дополнительно выявлены отдельные смешанные подписи приложения рисования, вибрации, системных материалов и ретро-терминала. Технические команды терминала и внутренние пути хранилища не переименовываются.

### Публичный сайт

Обычные элементы навигации, форм, уведомлений и CTA преимущественно русские. Названия каналов Telegram и WhatsApp, марки технологий, SITEVL LAB, SEO, API и форматы файлов оставлены без перевода. Маркетинговые тексты не переписывались без причины.

## Намеренно оставлено на английском

- Бренды и продукты: SITEVL, SITEVL Studio, SITEVL LAB, Telegram, WhatsApp, GitHub, Vercel.
- Технологии и форматы: HTML, CSS, JavaScript, TypeScript, React, Vite, Three.js, WebGL, API, URL, SEO, JSON, PNG, JPEG, SVG, WebP, AVIF, PDF.
- Системные обозначения: IndexedDB, localStorage, FPS, CPU, GPU, RAM, BIOS, CRT.
- Команды терминала: `help`, `ls`, `cd`, `pwd`, `clear`, `echo`, `cat`, `date`, `whoami`, `history`, `open`.
- Атмосферные элементы экспериментов: CORE, CSS GRID, EVENT LOOP, FIREWALL и стилизованные имена системных файлов.
- Вымышленные названия брендов в шаблонах, например NORTH CODE и DEVICE LAB.

## Сторонняя библиотека Puck

Для встроенных строк используется публичное свойство `dictionary` библиотеки `@puckeditor/core`. `node_modules` и внутренний DOM библиотеки не патчатся. Будущие новые строки Puck, для которых библиотека не предоставит ключ словаря, потребуют повторного аудита после обновления зависимости.

## Автоматическая защита

Добавлен lightweight-тест критических русских подписей Studio и словаря Puck. Он намеренно проверяет отображаемые значения, а не английские ключи и типы, чтобы не повредить схемы, импорт, экспорт и сохранённые проекты.
