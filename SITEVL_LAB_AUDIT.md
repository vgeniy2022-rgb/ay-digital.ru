# SITEVL LAB: аудит до переработки

Дата: 2026-08-28

## Текущее устройство

- `/lab` использует публичный `AppLayout` и выводит обычную сетку ссылок.
- Эксперименты находятся в `src/pages` и связаны общими компонентами из `src/components/lab`.
- Доступны Admin Demo, Architecture Explorer, Website Evolution, SEO Visualizer и legacy landing builder.
- SITEVL Studio уже вынесен в изолированный lazy-модуль `src/features/site-builder` и работает на `/studio`.
- Three.js уже установлен и используется другими визуальными страницами сайта.
- Единого прогресса, достижений, звуковых настроек и связи между экспериментами нет.

## Проблемы

1. LAB выглядит набором несвязанных демонстраций, а не цельным продуктом.
2. Все LAB-страницы рендерятся внутри коммерческой шапки, футера и фиксированных элементов.
3. Нет единого route shell, визуального языка и системных состояний.
4. Нет игр, физической песочницы, OS, retro-среды и infinite canvas.
5. Нет общего lifecycle-контроля анимационных циклов и cleanup-соглашения.
6. Старые карточки перегружены пояснениями и не дают визуального preview эксперимента.

## Что сохраняется

- Существующая React/Vite/TypeScript архитектура и React Router.
- SITEVL Studio как рабочий Website Builder без переписывания ядра.
- Старые компоненты и страницы остаются в Git и могут использоваться вне новой LAB-навигации.
- `three`, Framer Motion, Lucide и существующая SEO-инфраструктура.
- Старые URL получают redirect, а не 404.

## Что заменяется

- Главная `/lab` заменяется экспериментальной панелью из семи модулей.
- LAB получает отдельный fullscreen route branch без публичного Header/Footer/CTA.
- Разрозненные старые LAB-маршруты убираются из навигации и перенаправляются на новую главную.
- Добавляется изолированный модуль `src/features/lab` с отдельными lazy chunks.
- Добавляется versioned localStorage для explored state, достижений, mute и experiment data.

## Ограничения

- Backend и аккаунты не добавляются.
- 3D-объекты процедурные; copyrighted assets и логотипы систем не используются.
- Физика 2D и Physics Lab намеренно компактная и контролируемая, без тяжёлого engine bundle.
- Sensor APIs активируются только после действия пользователя и имеют текстовый fallback.
